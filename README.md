🐺 MWSD — Monwhooper Website
MWSD (MonWhooper · Stay Dangerous) is a high-end, performance-first website built on Next.js, Tailwind CSS, and shadcn/ui, designed as the digital flagship for the Monwhooper brand.
This project focuses on strong visual identity, conversion-oriented layouts, and modern UI/UX execution, while remaining clean, extensible, and production-ready.
🔗 Live Site
🌐 Production: https://monwhooperwebsite.vercel.app
🧪 Preview / Staging: Vercel preview deployments (per commit)
🧠 Design Philosophy
MWSD is built with the following principles:
Minimal but aggressive visual language
Typography-led identity (custom DX Gotha branding)
No bloat — only components that earn their place
Desktop-first polish, mobile-perfect execution
Conversion awareness without sacrificing aesthetics
🛠 Tech Stack




Framework: Next.js (App Router)
Styling: Tailwind CSS v4
UI System: shadcn/ui
Language: TypeScript
Icons: Lucide
Fonts: Custom DX Gotha (brand typography)
Deployment: Vercel
✨ Key Features
🐺 Custom Brand Identity
Monwhooper logo system, MWSD wordmark, and DX Gotha typography
🧭 High-End Navigation
Desktop + mobile navigation with sheet menus and blur effects
⚡ Performance-First Build
Optimized layouts, minimal JS, modern Next.js tooling
🌗 Dark Mode by Design
Dark-first aesthetic with controlled color tokens
♿ Accessible Components
Built on accessible shadcn/ui primitives
🎯 Conversion-Aware Layouts
Hero sections, CTAs, and flow designed with intent
🧱 Component Architecture
This project uses a section-based layout system, making it easy to iterate or extend.
Core Sections
Navbar
Custom MWSD branding, DX Gotha typography, mobile sheet navigation
Hero
High-impact hero layout designed for message clarity and authority
Items / Features
Modular grids for feature presentation and value props
Stats
Clean metric displays for credibility and social proof
FAQ
Accessible accordion-based FAQ sections
CTA
Strong call-to-action blocks with visual emphasis
Footer
Minimal, brand-consistent footer layout
